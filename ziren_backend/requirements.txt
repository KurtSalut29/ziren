# predict.py's normalise() fuzzy-matches unrecognised words against the
# emergency vocabulary, importing rapidfuzz inside a try/except ImportError
# that silently passes. Pinned here so that swallow can never be what decides
# the behaviour — off by accident and off by decision are indistinguishable in
# production and are not the same thing.
#
# The fuzzy pass itself is DISABLED. Measured on the release's own test split,
# it downgrades severity more often than it raises it — see the note on
# triage_service.FUZZY_NORMALISATION for the numbers.

# Speech-to-text for the resident's voice note (optional).

# Optional on purpose. transcription_service treats a missing engine as a
