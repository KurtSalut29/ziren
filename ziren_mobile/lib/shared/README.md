# shared/

Reusable UI widgets, themes, and assets used across multiple features.
Nothing in here should import from a specific feature folder.

## Planned sub-folders
- `widgets/`  — common UI components (buttons, inputs, loaders, snackbars)
- `theme/`    — app color scheme, text styles, spacing constants
- `assets/`   — static asset references (image paths, icon keys)
